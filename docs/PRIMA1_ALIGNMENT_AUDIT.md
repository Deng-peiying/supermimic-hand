## 打印修正

终端采用G1的单行结构，原始完整JSON继续留在metrics.jsonl。
train_ret = 各结束回合的平均单步奖励 / 理论最高单步正奖励；本任务最高值0.124。
这与G1的回合归一化方式一致，但奖励定义不同，不能据此横向比较任务表现，也不是成功率。
例如原始0.04372355显示为0.353。

明确使用nse8_fit：它来自WM训练批次，不是G1日志中独立重采样的online_nse_8step。
新进程记录sim/wm/pi主机分段耗时；旧日志没有该字段，因此查看器不补造耗时。
现有进程已加载旧打印代码；用scripts/tail_pen_log.py读取JSONL即可即时获得单行显示。
本地loop.py修正只影响下一次启动，不能声称修改文件会热更新当前进程。

## 已一致的机制

4096环境、320000步预算、40步预热、UTD0.4；每次WM更新10批、8步窗口；
32步可微想象、gamma0.99、GAE lambda0.95、Critic 5轮×4小批；
学习率2e-4及共享余弦调度（250000步衰减至3%）；4000步保存；
学习动力学和终止头，解析奖励；冻结WM参数对Actor做BPTT；
未来10帧参考、奖励乘控制周期。未来参考内容因无视觉任务限制仅含手关节角。

## 未对齐及分类

| 项目 | G1实现/默认配置 | Prima1 v4 | 判断 |
|---|---|---|---|
| 困难采样的回报尺度 | 用与奖励一致的g_max归一化 | 硬编码6.2/(1-gamma)，漏乘dt | **遗漏：当前尺度大50倍，困难权重更接近均匀；应单独修正并记录实验边界** |
| WM隐藏层 | 2048×3 | 512×3 | 容量选择，非任务硬性要求 |
| WM/policy batch | 默认2048/4096；此前5090 G1实验为2048/2048 | 1024/512 | 显存/吞吐选择，并非完全一致 |
| Actor | 目标编码器与解码器，默认2048/1024/512/256 | 128×2残差MLP，限幅及限位 | 明显结构差异；保留模型式训练不代表网络完全相同 |
| 历史窗口 | 10帧 | 30帧 | 部分可观测转笔的适配选择 |
| Critic | 256/128；在线自身自举 | 256×3；EMA目标网络tau0.005、存活概率加权拟合 | 数值稳定化改动，非原始G1机制逐项复现 |
| Replay容量 | 每环境1000 | 256 | 资源选择 |
| 随机化 | 观测、动作、重置、更多物理参数 | 动作噪声、摩擦、PD增益；重置速度零 | 当前鲁棒性范围更窄；不等于真机就绪 |
| 采样起点 | 多片段区间采样 | 单片段，额外约20%首帧；允许倒数第一转移 | 人工放笔验证选择，结束比例不能当完整成功率 |
| 仿真接口 | mjlab管理式环境 | 直接MuJoCo Warp批量环境，CPU独立评估 | 任务后端差异；CPU/GPU接触不完全相同 |
| 日志统计 | 周期聚合，单独WM在线误差，TensorBoard | 最近一次WM/Actor更新，JSONL，末步奖励分项 | 诊断功能尚未完全对齐；本次不增加采样以免扰动随机序列 |
| 编译/分布式 | 支持torch.compile、分布式同步 | 默认关闭compile、单GPU | 性能/部署差异 |
| 成功定义 | 人形跟踪与跌倒指标 | 笔偏离参考10cm失败，片段末端结束 | 任务必须独立定义，不可直接互换 |
