# Prima1 函数与公式审计及修正

2026-11-01。v4在13252步保存停止，本次修正标记为v5，Actor接口仍为v4的未来10帧接口。

## 已修正

1. ReturnSampler旧分母6.2/(1-gamma)没有随dt缩放。现在从环境奖励权重和管理器scale计算单步上界并传入采样器，默认0.124/(1-gamma)。新增尺度不变性测试：奖励与上界同时乘0.02，给定相同随机种子时采样帧完全一致。
2. 想象到参考末帧后原先仍执行Actor/WM，仅把奖励乘0。末端奖励和自举掩码虽正确，后续无效预测仍可能溢出，而0乘NaN并不为0。现在仅对未结束样本推进Actor/WM，末端状态和历史冻结。此项为数值边界防护，不宣称已观察到它引起此前critic发散。
3. WM终止特征尺度改为显式读取环境drop_distance_m，避免将来改真实终止阈值后WM仍保留构造默认值。
4. 配置描述改为实际使用的学习终止头；旧描述survival_softness只对应诊断sigmoid，不应冒充训练实现。
5. 日志采用单行格式，完整JSON保留；无结束回合时train_ret显示nan而非伪零。新进程记录阶段耗时。

## 公式核对

r = dt × [exp(-mean(dq²)/0.15²) + 0.2 exp(-mean(dqd²)/3²)
+ 3 exp(-||dp||²/0.025²) + 2 exp(-(1-(u·u_ref)²)/0.2)
- 20 ||dp||² - 0.02 mean(((target-previous)/0.12)²)]。

dt只由奖励管理器乘一次。物理和想象共用奖励函数；比较step后的状态与下一参考帧。
动作惩罚的previous是此前执行目标，真实step使用加噪并限幅后的执行目标，WM监督也使用执行动作。
笔模型长轴为局部X，与pen_axis从wxyz四元数计算出的第一旋转列一致。
笔轴对正/反方向等价；四元数q/-q等价。关节误差按22维取均值，笔位置误差按3维平方和。

新增独立标量公式对照和float64有限差分梯度检查；终止当步奖励保留，后续奖励和价值自举为零。
保留现有积分与MuJoCo对照、回放不跨reset、参考未来窗口、Actor无笔真值、导出一致性测试。

## 仍需明确的设计局限（本次没有擅自改奖励）

- 轴奖励等价于exp(-sin²(theta)/0.2)，theta=90°时梯度严格为零；不代表程序求导错误。可用初始姿态/课程保证处于有用区域，或在后续实验研究时序/角速度项，不能未经实验声称换公式就更好。
- 距离平方惩罚无下界，WM严重外推仍可能产生大负值；本次修复末端无效推进，不等于解决所有模型误差。
- 当前只跟踪关节、笔中心和无向笔轴，没有接触保持、力矩/过流、自碰撞、连续转数的独立目标。
- 真实失败阈值只有笔位置误差10cm。reference_end_count和completed_without_drop不能证明连续转笔成功；评估明确返回spin_success=None。
- 人工验收是几何验收，零速度随机帧重置不证明所有片段中间姿态动力学可实现。
- OfflineController仍是离线适配器。历史中的last_target是输出目标，SDK若限幅/拒绝执行必须返回实际目标后接入，不能直接宣称可上真机。
- CPU/Warp接触存在差异，不能只用CPU回放判定训练后端效果。

网络容量、batch、EMA目标critic等差异是此前显式选择，本次未借公式检查重新设计网络。
v4检查点不允许直接resume到v5；保留其原始权重和日志。v5自身支持恢复，跨版本仅可明确initialize兼容Actor开启新实验。
