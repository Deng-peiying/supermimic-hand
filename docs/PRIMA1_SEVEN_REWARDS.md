# 六项奖励 + 翻转角速度跟踪

六项基线已提交：2afd394。此次新增项在此提交之后，未覆盖基线。
原有六项公式、权重、容差不变。第七项默认weight=0.5，std=3 rad/s，属于待实验验证的初值。

设u为笔长轴在掌心固定坐标系的方向，MuJoCo自由关节角速度omega_body先乘旋转矩阵R：

omega_flip = R omega_body - ((R omega_body)·u)u

r_flip = dt × 0.5 / (1 + ||omega_flip - omega_flip_ref||² / 3²)

去除轴向自旋，但保留翻转向量的正负方向。两端等价不会让正反翻转获得同样奖励。
有理核在大速度误差时比指数核更慢饱和；仍有有限梯度弱化，并非解决全部训练困难。
轴方向奖励在90°的驻点仍存在，新项提供独立速度信号，而不是把该驻点改没。

参考从已验收轨迹的相邻长轴最短弧计算，间隔角速度=轴叉积方向×atan2(叉积模,点积)/dt。
内点平均左右区间，首尾单侧；去除轴向分量后转换到物体系存入object_ang_vel字段。
相邻轴接近180°时拒绝重建，避免静默产生不可靠方向。hold阶段参考速度为零。
原始candidate.npz、验收文件、资产均不修改，不重新重定向；仅生成训练参考派生量。

训练、CPU评估、WM想象使用同一参考生成器和奖励函数。Actor输入/导出仍只有手信息。
最高单步正奖励变为0.134（6.7×0.02）；训练采样器与日志从配置动态计算，不沿用0.124。
旧六项检查点任务配置校验将拒绝直接resume；可显式initialize兼容Actor开新实验。
尚未启动新的长期训练，也未声称该奖励已提升效果。

验证：26项相关测试通过，包含基线六项不变、独立公式与有限差分梯度、恒速翻转参考、
四元数符号不变、长轴自旋排除、反向翻转惩罚、坐标系转换和90°处速度梯度。
